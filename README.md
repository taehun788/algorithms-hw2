# 고급알고리즘 과제 2 · URL 단축기

개별 체이닝과 선형 탐지를 같은 URL 단축기에서 비교한다. Python 3.10 이상, 표준 라이브러리만 사용한다.

| 명령 | 동작 |
| --- | --- |
| `make test` | 전체 단위·HTTP 테스트 |
| `make serve` | 개별 체이닝 서버 |
| `make serve TABLE=probe` | 선형 탐지 서버 |
| `make experiment` | 체이닝의 적재율별 비용 측정 |
| `make compare` | 두 방식의 성공·실패 탐색 비용 비교 |

웹 서버는 기본 8000번 포트에서 열린다. 초기 테이블 크기는 16이다. 새 서버에서 `https://github.com`과 `https://docs.python.org/3/`를 차례로 넣고 `/table`을 연다. 각 URL의 계산을 펼쳐 시작 칸 5, 방문 경로, 최종 위치를 비교할 수 있다. 두 번째 주소의 마지막 슬래시도 입력한다. 단축 링크는 각각 원래 URL로 이동한다. 실습용 데이터는 서버를 끄면 사라진다.

Codespaces에서는 Ports 탭에서 8000번 포트를 전달하고, 휴대폰 확인 중에만 공개한 뒤 다시 Private으로 돌린다.
